# MacShow

An open-source video and music player for macOS.

## Status

Early development: a bare player window that plays video and audio files (MKV, FLAC, M4B and anything else [mpv](https://mpv.io) handles) through [MPVKit](https://github.com/mpvkit/MPVKit).

Requires macOS 14+ and Xcode. Run it with:

```bash
swift run MacShow [file]
```

See the [roadmap](ROADMAP.md) for where it's going.
